RASH PORTFOLIO v5

SEE IT ON YOUR PHONE
  A) Same Wi-Fi: run Live Server in VS Code, then on your phone open http://YOUR-PC-IP:5501
     (find the IP with ipconfig on Windows or ifconfig on Mac/Linux, e.g. 192.168.1.23).
  B) Free public link: drag this whole folder onto https://app.netlify.com/drop
  C) GitHub Pages: push the folder to a repo and turn on Pages in Settings.

0. Hero photo: save your picture as assets/rash.jpg (portrait, about 800x1000, face in the
   upper half). Until it exists, a big R shows in the frame.

1. Resume: export a copy WITHOUT your date of birth, father's name, home address and
   phone number, save it as assets/resume.pdf (the Download resume buttons use it).
2. Links: search index.html for "YOUR". Any link still containing YOUR-... is hidden
   automatically. Fill in: YouTube handle, novel link, client website link.
3. Form: opens the visitor's email app by default. For a real form, make a free one at
   formspree.io and replace YOUR_FORM_ID in index.html.
4. Skill logos load from the internet (jsDelivr and Simple Icons). Offline, the pills
   still show with text only.
5. Open index.html with VS Code Live Server (port 5501 is set).
